# voice_ime
自适应VAD语音输入法

---

## 项目简介

VoiceIME是一款基于环境噪声自适应 VAD（Voice Activity Detection）的智能语音输入法。项目采用 Silero VAD + FunASR Paraformer 双模型架构，结合实时噪声估计与动态阈值调整，实现高精度的语音活动检测与流式语音识别。支持实时字幕输出、多轮上下文理解、语音指令、音频特征可视化、LLM 文本纠错等高级功能，适用于各种噪声环境下的语音输入场景。

---

## 核心特性

- **自适应 VAD 检测**：基于最小统计量和指数移动平均的噪声估计，根据信噪比动态调整检测阈值
- **流式语音识别**：不等说话结束即可开始识别，实现增量式文本输出
- **逐字/逐词实时显示**：字符级别动画效果，新识别文字逐字出现，视觉反馈清晰
- **多轮上下文理解**：自动维护对话历史与主题上下文，结合上文纠正同音词歧义，提升长文本识别准确率
- **语音指令**：支持"换行""删除"等语音命令
- **音频特征工程**：实时FFT频谱、梅尔频谱、过零率、谱质心计算与语音质量评估
- **可视化分析界面**：频谱图、波形图、噪声水平、阈值变化、检测状态实时展示
- **LLM 文本纠错**：自动去除语气词、修正标点符号，结合上下文消除歧义
- **连续模式**：支持最长5分钟持续录音，麦克风始终保持开启
- **识别记录持久化**：普通模式与连续模式分别保存至独立目录

## 使用说明

### 热键操作

| 热键 | 功能 | 说明 |
|------|------|------|
| **F8**（按住） | 语音录制 | 按住说话，松开后自动识别并输入 |
| **F6** | 清除上下文 | 重置多轮对话历史 |
| **F7** | 语音指令开关 | 启用/禁用语音指令功能 |
| **F9** | 查看设置 | 弹出当前配置信息窗口 |
| **F10** | 连续模式 | 切换连续录音模式（最长5分钟） |
| **F11** | 音频分析 | 打开实时频谱、逐词显示与分析窗口 |
| **F12** | 退出程序 | 完全退出 VoiceIME |

### 普通模式

1.把光标放在新的记事本上
2. **按住 F8** 开始说话
3. 松开 F8 后，系统自动识别，无需键盘操作
4. 悬浮窗口显示识别状态和结果

### 连续模式

1. 同样的，新建记事本，把光标放在上面，按 **F10** 开启连续模式，麦克风持续开启
2. 可以连续说话，系统实时流式识别
3. 再次按 **F10** 停止录音并处理全部音频
4. 识别结果自动输入并保存到 `history/continuous/` 目录

### 语音指令

在说话时（普通模式或连续模式），说出以下指令关键词即可触发对应操作：

| 语音指令 | 触发关键词 | 执行动作 |
|----------|-----------|----------|
| **换行** | "换行"、"下一行"、"回车" | 按下回车键，光标换到下一行 |
| **发送** | "发送" | 按下回车键发送当前文本 |
| **删除上一个词** | "删除上一个词"、"删除前一个词"、"删词" | 删除光标前一个词 |
| **删除一句话** | "删除一句话"、"删除这句话"、"删句" | 删除光标所在句子 |
| **全部删除** | "全部删除"、"删除所有"、"清空" | 全选并删除当前全部文本 |
| **撤销** | "撤销"、"撤回" | Ctrl+Z 撤销上次操作 |
| **全选** | "全选" | Ctrl+A 全选文本 |
| **复制** | "复制" | Ctrl+C 复制所选文本 |
| **粘贴** | "粘贴" | Ctrl+V 粘贴剪贴板内容 |
| **开头** | "开头"、"最前面"、"文档开头" | 跳转到文档最开头 |
| **结尾** | "结尾"、"最后面"、"文档结尾" | 跳转到文档最结尾 |

语音指令会从识别文本中自动检测并去除，其余正常文本照常输入。可通过 **F7** 键或系统托盘菜单随时开关语音指令功能。

### 多轮上下文理解

VoiceIME 会自动维护对话历史记录（最近5轮），在 LLM 纠错时提供上下文信息：

1. **自动纠错**：结合上文主题消除同音词歧义（如"公鸡"vs"攻击"根据技术主题自动选择）
2. **上下文提示**：当识别到模糊词汇时，LLM 会根据对话历史选择最合适的纠正
3. **清除上下文**：按 **F6** 或通过系统托盘菜单重置对话历史

### 逐字/逐词实时显示

在连续模式下，按 **F11** 打开音频分析窗口，可实时看到：

- **识别状态**：`[Recognizing]` 黄色前缀表示正在识别中
- **逐词动画**：新识别的文字逐个出现，视觉流畅自然
- **最终结果**：`[Done]` 绿色前缀表示该段识别完成

### 音频分析窗口

按 **F11** 打开分析窗口，可查看：

- **波形图**：实时音频波形显示
- **FFT 频谱**：频率分布可视化（绿-黄-红表示能量强度）
- **梅尔频谱**：人耳感知频率分布
- **VAD 状态**：语音活动检测实时状态
- **麦克风状态**：设备连接状态
- **运行模式**：普通/连续模式指示
- **指标面板**：SNR、噪声水平、VAD阈值、语音质量评分
- **流式识别**：实时增量逐字动画文本输出

## 技术架构

### 自适应 VAD 系统

```
音频输入 → 噪声估计 → SNR计算 → 动态阈值 → Silero VAD → 语音检测
```

- **噪声估计**：采用最小统计量跟踪 + 指数移动平均（EMA），实时估计环境噪声基线
- **自适应阈值**：根据 SNR 动态调整检测灵敏度
  - SNR < 0dB：阈值 +0.2（高噪声环境，提高检测门限）
  - SNR 0-5dB：阈值 +0.1
  - SNR 5-15dB：基准阈值 0.5
  - SNR 15-25dB：阈值 -0.1
  - SNR > 25dB：阈值 -0.15（安静环境，降低检测门限）
- **双重检测**：神经网络概率 + 能量阈值联合判断，降低误检率

### 流式识别流程

```
持续录音 → 重叠分块 → 噪声抑制 → 增量识别 → 部分结果 → 逐词动画 → 最终结果
```

- 每 2 秒音频块，0.5 秒重叠窗口
- 实时输出部分识别结果（类似字幕滚动）
- diff跟踪算法检测新增字符，逐词动画显示
- 说话结束后输出最终完整结果


### 多轮上下文理解流程

```
语音识别 → 上下文历史 → LLM纠错（含上下文） → 修正文本 → 更新历史
```

- **ContextManager**：维护最近5轮对话历史，提取核心话题关键词
- **LLMCorrector**：接收上下文提示词，结合原文进行歧义消除
- **循环更新**：每次识别结果自动追加到历史队列

### 语音质量评估

综合以下指标计算质量评分（0-1）：

| 指标 | 权重 | 说明 |
|------|------|------|
| SNR | 40% | 信噪比，越高越好 |
| 削波率 | 30% | 信号过载比例，越低越好 |
| 动态范围 | 20% | 信号幅度变化范围 |
| RMS 能量 | 10% | 平均信号强度 |

## 常见问题

### Q: 麦克风没有反应？
A: 运行 `python test_mic.py` 检查麦克风设备是否正常，确认系统已选择正确的输入设备。

### Q: 识别速度慢？
A: 首次运行需下载模型文件。如有 NVIDIA GPU，确保安装了 CUDA 版本的 PyTorch 以加速推理。

### Q: 热键不生效？
A: 确保程序以管理员权限运行，某些应用可能会拦截全局热键。

### Q: 如何启用 LLM 纠错？
A: 在 `.env` 中配置 `GEMINI_API_KEY` 和 `GEMINI_BASE_URL`，设置 `LLM_ENABLED=true`。

### Q: 语音指令不生效？
A: 按 **F7** 检查语音指令开关状态，确保已启用。指令关键词需清晰发音。

### Q: 上下文理解效果不明显？
A: 需启用 LLM 纠错功能才能使用上下文理解。上下文在持续对话中效果最佳，可按 F6 清除旧上下文。
